Frequently Asked Questions

Everything you need to know about the Yuva Frontend Web Developer Internship Week 1 submission.

What are the main requirements for the Week 1 Task? +

The task requires converting a wireframe into a static web page using clean semantic HTML5, well-structured CSS3 (Flexbox/Grid), and minimal JavaScript without relying on external frameworks like Bootstrap or Tailwind.

Is the web page responsive on all devices? +

Yes, the project is tested for mobile (phones), tablets, laptops, and desktop viewports. Media queries ensure text remains legible and layout elements stack gracefully with zero horizontal scroll bar overflow.

How do I run and deploy this project? +

Simply open `index.html` in any web browser or host it via GitHub Pages by committing the repository and enabling GitHub Pages from the repository settings menu.

How is accessibility handled in this static page? +

We use standard semantic tags (`header`, `nav`, `main`, `section`, `footer`), high contrast text colors, descriptive image `alt` text, visible keyboard focus indicators, and custom ARIA labels.
